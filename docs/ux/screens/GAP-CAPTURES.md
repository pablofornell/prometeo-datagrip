# DataGrip gap captures (2026-11-07)

Reference screenshots of real DataGrip 2026.3 (build DB-263.7307.216) for the gap list in the UX-parity brief.
Same method as `docs/ux/datagrip-map.md` § "How this was captured": private Xvfb `:8` (1920x1080x24) + private i3 (no borders, floating), main window 1600x1000 at 0,0, Inter 13, scale 1.0, captured with `ffmpeg x11grab` at 1600x1000+0+0 (1 px = 1 CSS px). Theme Islands Dark (editor scheme Islands Dark) for `*-dark`, Islands Light for `*-light`. Keymap XWin.
Test data: SQLite `/tmp/claude-1000/ux-sample.db` (data source `ux-sample.db`) and PostgreSQL 16 container on 127.0.0.1:54329, schema `shop` (data source `postgres@localhost`).

General notes:
- Dialogs have no window title/frame in these shots: there is no decorating WM on the Xvfb display, so JetBrains dialogs (which use native title bars on Linux) show only their content. Measure content, not chrome.
- Popup menus: mouse clicks on popup-list items often did not register under xdotool unless preceded by a hover; keyboard (arrows + Enter) always worked. Popups that don't fit below the anchor are shifted up, not flipped.
- Items with a `b`/`c` suffix are extra states captured alongside the requested one.
- Out-of-scope UI visible in some shots (do not replicate): "Add to Agent Context"/"Agent Sessions" (AI), "New Session" (AI) in the toolbar, "Trial" status-bar badge, "Send to Workspace Console [New]" and the "Query across your data sources directly … Open in Workspace console" promo banners in Export/Import dialogs, JetBrains-Account login prompt on the Data Source Templates page (not captured).

All 41 gap items (45 files) captured; NOT CAPTURED: none. Item 131 has no exact equivalent in 2026.3 (see its line).
